# Aura – Your Space (Mobile MVP)

A premium, calm, and classy social mobile application built with React Native and Expo.

## 🚀 Features Implemented

### MVP Complete
- ✅ **Onboarding Flow**: Language selection (6 languages), interests, and location
- ✅ **Home Feed**: Premium feed with FlashList for 60fps scrolling  
- ✅ **Live Pulses**: Real-time guided participation rooms
- ✅ **Discover**: Search, interests management, and trending content
- ✅ **Create Moments**: Text + optional images (max 2)
- ✅ **Direct Messaging**: Text-only conversations
- ✅ **Profile & Settings**: User profile with language switching
- ✅ **Multi-language Support**: English, Hindi, Kannada, Telugu, Tamil, Malayalam

## 📱 Tech Stack

- React Native + Expo (SDK 51)
- TypeScript (strict mode)
- React Navigation
- TanStack Query
- NativeWind (Tailwind)
- Reanimated v3
- FlashList
- expo-image
- MMKV
- i18next
- Zod

## 🛠 Installation

```bash
cd aura-frontend
npm install
npm start  # Start Expo
npm run ios    # Run on iOS
npm run android # Run on Android
```
